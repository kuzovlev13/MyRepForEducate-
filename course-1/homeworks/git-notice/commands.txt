git init - Инициализация нового локального репозитория в текущей папке
git add [файл] - Добавление одного или нескольких файлов из рабочего каталога в индекс (staging area)
git add . - Добавление всех измененных и новых файлов в текущем каталоге в индекс
git commit -m "[сообщение]" - Сохранение изменений, добавленных в индекс, в репозитории с указанным сообщением
git status - Отображение состояния рабочего каталога и индекса, показывая, какие файлы были изменены или добавлены
git log - Показ истории коммитов в репозитории
git pull - Загрузка изменений из удаленного репозитория и слияние их с текущей веткой
git push - Отправка локальных коммитов в удаленный репозиторий
git branch - Управление ветками: создание, перечисление, удаление
git checkout [имя_ветки] - Переключение на другую ветку
